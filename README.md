# Online Retail Sales Analysis | Excel

An Excel-based sales analysis project exploring revenue trends, product performance, and country-level sales for an online retailer.

## Project Overview

This project analyzes the UCI Online Retail dataset using Microsoft Excel. It focuses on understanding sales performance across countries, identifying top-performing products, and examining monthly sales trends through an interactive dashboard.

## Dataset

- **Source:** [UCI Machine Learning Repository — Online Retail](https://archive.ics.uci.edu/dataset/352/online+retail)
- **Business:** UK-based online retailer
- **Original dataset period:** December 2010 – December 2011
- **Original records:** 541,909 transactions

The original dataset includes invoice numbers, product codes, descriptions, quantities, invoice dates, unit prices, customer IDs, and countries.

## Tools and Techniques

- **Microsoft Excel** — analysis and dashboard development
- **Power Query** — data cleaning and preparation
- **Excel formulas** — sales revenue calculation
- **PivotTables and PivotCharts** — summarization and visualization
- **Excel Data Model** — distinct invoice counting

## Project Workflow

1. Imported the original retail transaction dataset.
2. Prepared and cleaned the data using Power Query.
3. Calculated sales revenue using quantity and unit price.
4. Summarized sales performance using PivotTables.
5. Created charts to explore country, product, and monthly sales patterns.
6. Organized the visualizations into an Excel dashboard.
